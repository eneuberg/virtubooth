# virtubooth

A digital photo booth for parties, self-hosted on a Raspberry Pi. Guests scan
a QR code and land on one of three phone-friendly web pages:

- **Beer Cam**: photograph your drink inside a framing guide. Every photo
  becomes a frame of a "1 million beers" timelapse.
- **Photo Booth**: live camera with real-time filters, countdown, save to
  phone + upload.
- **Live Wall**: fullscreen page for a TV/projector showing new photos as they
  arrive, the beer counter and a join QR code.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md) for the proposed
architecture and [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) for the spec.
